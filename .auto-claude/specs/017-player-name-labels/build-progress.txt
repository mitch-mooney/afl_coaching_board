ISSUE FOUND AND FIXED:

Bug Discovery:
While verifying the load flow, I found a critical bug that would have prevented
player name restoration from working:

1. playbookStore.ts loadPlaybook() was returning Promise<void>
   - It set currentPlaybook but did NOT return the playbook object

2. usePlaybook.ts loadScenario() expected a returned playbook:
   ```typescript
   const playbook = await loadPlaybookFromStore(playbookId);
   if (playbook) {  // This would always be false!
     usePlayerStore.setState({ players: playbook.playerPositions });
   }
   ```
   - playbook would be undefined because loadPlaybook returned void
   - The if(playbook) check would fail
   - Player state (including names) would NOT be restored!

FIX APPLIED:

1. playbookStore.ts interface (line 39):
   - Changed: loadPlaybook: (id: number) => Promise<void>;
   - To:      loadPlaybook: (id: number) => Promise<Playbook | undefined>;

2. playbookStore.ts implementation (line 93):
   - Added: return playbook;
   - Now returns the playbook object for usePlaybook.ts to use
